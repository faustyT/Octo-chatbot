# Octa - Voice and Text Conversational Assistant

Octa is a terminal-based AI assistant that lets you interact via voice or text. It performs reasoning, provides educational insights, and even does web searches—all in a friendly, smart assistant style.

##  Features
- 🎙️ Voice recognition with speech-to-text
- 🧠 Reasoning and conversation via Mistral (via OpenRouter)
- 🔍 Google-powered web search
- 📚 Wikipedia-based educational summaries
- 💬 Text-based conversation fallback
